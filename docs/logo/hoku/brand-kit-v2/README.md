# HOKU – Brand-Kit v2 / Cyan

Aktuelle Auswahl vom 02.11.2026. Start: HOKU-Uebersicht.png und HOKU-Brand-Guide.html.

Hoku mit natürlicher Pupille in Cyan ersetzt die alte pupillenlose Kugel. Schriften, gleich breite Unterzeile, Kompaktlogo und Plakette 03 bleiben erhalten. Das KI-Button-Symbol bleibt unverändert.

Ordner und Größen sind im Guide beschrieben. Der bestätigte Bildmaster liegt unverändert unter 04-Icons/hoku-app-cyan-original.png. PNGs und SVG-Layouts enthalten Raster-Hoku; SVGs sind keine vollständig vektorisierten Master. Keine automatische Änderung der App oder Veröffentlichung.

Erzeugen: node docs/logo/hoku/brand-kit-v2/QUELLEN/build.cjs
Prüfen: node docs/logo/hoku/brand-kit-v2/QUELLEN/verify.cjs
