# HOKU – dunkles Cyan-App-Icon

Zusätzliche dunkle Variante des aktuellen Hoku mit natürlicher Pupille und nahezu weißem Pupillenrand. Das hellere Cyan-Icon bleibt im übergeordneten Ordner erhalten.

## Dateien

- hoku-app-cyan-dunkel-original.png: unveränderter 1254-px-Master.
- hoku-app-cyan-dunkel-{Größe}.png: 1024, 512, 256, 192, 180, 167, 152, 144, 128, 120, 96, 87, 80, 76, 72, 64, 60, 58, 48, 40, 32, 29, 20, 16 px. Alle Exporte sind quadratische RGB-PNGs ohne Alphakanal.
- hoku-favicon-dunkel-{Größe}.png: 16, 32, 48 und 64 px, mit engerem Ausschnitt für Browser-Tabs.
- favicon.ico: dieselben vier Favicon-Größen.
- favicon-dunkel.svg: eingebetteter Rastermaster, kein reiner Vektor.

## Auswahl

1024 px als großer App-Export; 512/192 px für Web-App-Verwendungen; 180/167/152/120 px und die weiteren Zwischenstufen für passende iPhone-/iPad-Bildflächen; 48/72/96/144/192 px für entsprechende Android-Bildflächen. Die Einbindung richtet sich nach dem jeweiligen Projekt. Das bestehende iOS-Projekt verwendet ein universelles 1024-px-Icon. Dieses Paket enthält Bilddateien, keine neu konfigurierte App oder Android-Adaptive-Icon-Ebenen. Die Fassungen behalten die sicheren Außenränder des bestätigten Motivs bei.
