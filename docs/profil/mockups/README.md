# Profil-Mockups (Brainstorming 31.10.2026)

Klickbare Entwürfe aus der Planung von Profil, Freunden und Chat. Im Browser öffnen.

- `profil-2a.html` — **Schritt 2a** (Stand 31.10.2026, auf Basis von v3): Sichtbarkeit pro Feld mit Chips, Symmetrie-Regel ohne Lücken, Einstellungen hinter ⚙︎, „Wer sieht was“, Blockiert-Liste, Bild-Check, Web-Link-Zwischenstand. Spec: `docs/superpowers/specs/2026-10-31-profil-p2a-sichtbarkeit-design.md`.
- `profil-v3.html` — Gesamtentwurf: vier Ansichten (eigenes Profil, als Freund, als App-Nutzer, Web-Link), Sichtbarkeits-Chips pro Feld, Gesamtfortschritt mit Richtung je Wert, Story, Titelbild, Über mich, Wearables, Freunde/Anfragen, Chat mit Handels-Warnung, Melden/Blockieren, Einstellungen nach Vorbild sozialer Netzwerke.
- `profil-v2.html`, `profil-v1.html` — frühere Stände.
- `hoku-code.html` — runder Hoku-Code: Variante A (runder QR-Code, gewählt) und B (eigener Ring-Code, zurückgestellt). Muster nur nachgemacht, nicht scannbar.

Seit v3 entschieden: Geschlecht nur als Zeichen neben dem Namen (keine Karte), Herkunft als Flagge mit Kürzel neben dem Namen (keine Kachel), Ziel-Tags ohne Obergrenze als wischbare Zeile, kein Hinweis auf verborgene Bereiche. Alles Weitere: `docs/superpowers/specs/2026-10-31-profil-social-gesamtbild-design.md`.
