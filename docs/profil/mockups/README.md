# Profil-Mockups (Brainstorming 31.10.2026)

Klickbare Entwürfe aus der Planung von Profil, Freunden und Chat. Im Browser öffnen.

- `profil-v3.html` — **aktueller Stand**: vier Ansichten (eigenes Profil, als Freund, als App-Nutzer, Web-Link), Sichtbarkeits-Chips pro Feld, Gesamtfortschritt mit Richtung je Wert, Story, Titelbild, Über mich, Wearables, Freunde/Anfragen, Chat mit Handels-Warnung, Melden/Blockieren, Einstellungen nach Vorbild sozialer Netzwerke.
- `profil-v2.html`, `profil-v1.html` — frühere Stände.
- `hoku-code.html` — runder Hoku-Code: Variante A (runder QR-Code, gewählt) und B (eigener Ring-Code, zurückgestellt). Muster nur nachgemacht, nicht scannbar.

Seit den Mockups entschieden: Geschlecht nur als Zeichen neben dem Namen (keine Karte), Ziel-Tags ohne Obergrenze als wischbare Zeile. Alles Weitere: `docs/superpowers/specs/2026-10-31-profil-social-gesamtbild-design.md`.
