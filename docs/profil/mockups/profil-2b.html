Gesamtfortschritt und Abzeichen. Rechnung nach deiner Vorgabe: Prozent der positiven Veränderung vom Start bis jetzt. In der Aufschlüsselung lässt sich die Richtung je Wert ändern, der Ring rechnet mit. Daten erfunden (Mara, Start 14.03.2026).

Rechnung
Je Wert (ab zwei Messungen):
runter: (Start − jetzt) ÷ Start
hoch: (jetzt − Start) ÷ Start
Zielbereich: Anteil im Bereich, (jetzt − Start) ÷ Start
Beispiel: 120 → 100 kg, runter = +16,67 %.
Gesamt: Mittel je Bereich, dann Mittel der Bereiche, ohne Deckel.
